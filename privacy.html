Privacy Policy

Last updated: November 25, 2026.

"Code 3 Docket Analytics" is a private tool used only by the owner of the Code 3 Docket YouTube channel. It is not offered to the public.

What the tool accesses

With the owner's consent through Google sign-in, the tool reads read-only YouTube Analytics and YouTube channel data of the owner's own channel (views, impressions, click-through rate, audience retention, traffic sources).

How the data is used and stored

The data is used only to review the performance of the channel's own videos. It is stored on the owner's computer. It is not sold, shared with third parties, or used for advertising.

Google API Services User Data Policy

The tool's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

The owner can revoke access at any time at myaccount.google.com/permissions.
